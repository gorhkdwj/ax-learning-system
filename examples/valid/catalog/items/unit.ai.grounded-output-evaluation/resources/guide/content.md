# 근거 기반 출력 평가 가이드 예제

이 파일은 Phase 1 학습성과–Resource–검증 게이트 연결을 확인하기 위한 최소 예제입니다.
완성된 AI 평가 교재가 아닙니다.

## 예제 평가 상태

- `근거 있음`: 제공된 근거가 해당 주장을 직접 뒷받침합니다.
- `근거 부족`: 관련 근거는 있으나 주장 전체를 확인할 수 없습니다.
- `모순`: 제공된 근거와 주장이 충돌합니다.
- `판단 불가`: 필요한 자료나 평가 조건이 부족합니다.

실제 평가 기준은 대상 업무, 위험과 수용 기준에 맞추어 별도 Learning Set에서 구체화합니다.
