# 실용성 독립 감사: wp.human-ai-experience.breadth-a

## 범위

- D0/D2 평가 가능성, local·공개·합성 fixture와 실제 데이터 차단
- 설명·승인·memory·접근성·의인화 위험과 전문 이관
- 관찰 가능한 outcome, 표본 일반화와 실행 규모

감사자는 파일을 수정하지 않고 메인 세션만 교정을 반영했습니다.

## 1차 결과

| 심각도 | 건수 |
|---|---:|
| P0 | 0 |
| P1 | 4 |

1. 접근성 Resource의 소유권을 D0 요구 식별·라우팅으로 통일했습니다.
2. 설명 경험에 무설명 기준선 대비 잘못된 수용·거부 악화 여부를 추가했습니다.
3. 승인 경험에 봉인된 정답·필수 맥락과 잘못된 승인·거부·이관 0건을
   추가했습니다.
4. HAI 경험평가를 prebuilt prototype, 과업 3개, 오류 6개, 대표 사용자 또는
   proxy evaluator 3~5명과 150~180분 formative 범위로 제한했습니다.

## 재감사

| 심각도 | 건수 |
|---|---:|
| P0 | 0 |
| P1 | 0 |

- 공개·합성 입력과 local prototype만 사용하고 실제 개인정보·운영 계정·
  고위험 외부 변경을 차단합니다.
- 설명·승인·경험평가의 `measurement_hypothesis`를 보강한 D2 기준과
  동기화했습니다.
- 만족도·유창성·설명 선호를 과업성공·적절한 의존·통제·복구의 대리 지표로
  사용하지 않습니다.

## P2

- 승격 시 9개 후보의 공통 업무가치 가설을 후보별 관찰 가능한 실패 감소
  가설로 구체화합니다.
- 예상 시간은 prebuilt fixture·prototype 범위를 전제로 정규 메타데이터에
  기록합니다.

## 결론

최종 P0·P1은 0건입니다. 실용성 기준으로 9개 모두 평가 가능한 구조이나,
개인화·기억 후보는 근거 감사 결과에 따라 `deferred`로 유지합니다.
