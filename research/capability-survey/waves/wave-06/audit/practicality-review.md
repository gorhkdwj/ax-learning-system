# 실용성·안전 독립 감사: wp.independent-qa.stratified-a

## 범위

- 고위험·D3·논쟁 30개의 깊이·산출물·실패주입·복구·전문 이관
- 일반 층화표본 26개의 전이성·객관 검증·효과 주장
- Wave 5 신규 Unit 7개·Reference 7개·Set 1개의 실행 메타데이터·안전 Gate

## 1차 결과와 교정

| 심각도 | 건수 |
|---|---:|
| P0 | 0 |
| P1 | 0 |
| P2 | 2개 실행계약 범주 |

1. optional 외부 Reference를 가진 전략 Unit 7개의 `network_required`와 비용
   basis를 합성·공개 또는 승인된 비식별 fixture 평가 기준으로 정렬했습니다.
2. Unit 7개와 Set에 `required_before_activation` Gate와 입력정책을 추가했습니다.
3. 현행 업무분석과 과업 역할배분은 데이터 분류·최소수집·접근·보유·정리와
   개인정보·HR·노무·법무 이관을 실제 자료 overlay의 별도 승인조건으로
   고정했습니다.
4. 과업 역할배분의 “실제 표본” 표현을 봉인된 합성·공개 또는 승인된 비식별
   fixture 표본으로 교정했습니다.

## 최종 재감사

| 심각도 | 건수 |
