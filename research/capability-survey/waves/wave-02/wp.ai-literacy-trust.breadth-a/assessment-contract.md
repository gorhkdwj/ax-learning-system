# 평가 가설 계약: AI 리터러시·신뢰

> 이 문서는 후보 단계의 공통 평가 가설입니다. 정규 Unit 평가나 상세 교재가
> 아니며 사용자 승인과 파일럿 검증 전에는 합격 기준으로 확정하지 않습니다.

## 1. 역할별 목표 깊이

| 대상 | 기본 목표 | 적용 |
|---|---|---|
| 모든 구성원 | D0 또는 안내형 D1 | AI 기초, 허용·금지 경계와 이관 경로 인식 |
| 실제 AI 사용자·출력 검토자 | D2 | 과업 프레이밍, 출력 평가, 검증, 책임 있는 사용 |
| 승인자·고위험 업무 담당자 | D2 + 역할별 Overlay | 제공된 위험정책·승인·전문가 이관 경로 적용 |

모든 구성원에게 동일한 D2 수행을 요구하지 않습니다. 법률·정책·통제·전문
영향평가를 설계하는 능력은 이번 패키지의 평가 대상이 아닙니다.

### 후보 조합 기본값

| 조합 | 후보 |
|---|---|
| 전 구성원 D0·D1 공통 코어 | AI 기초·한계, 책임 있는 사용 경계, 영향 인식, AI 사용 투명성 |
| 실제 사용자·검토자 D2 수행 코어 | 과업 프레이밍, 출력 적합성 평가, 위험 비례 의존 |
| 빈번한 사용자·검토자·승인자 D2 Overlay | 신뢰 보정 |
| 기존 정본 재사용 | 근거·출처 검증 Unit, provenance Resource 후보 |

위험 비례 의존과 신뢰 보정은 같은 fixture를 사용할 수 있지만 전자는 제공된
정책에 따른 통제 선택, 후자는 인간의 수용·거부 판단 보정을 별도로 채점합니다.

## 2. 공통 fixture 표본

평가 세트는 다음 차이를 의도적으로 포함해야 합니다.

- 생성형 AI와 분류·추천·예측·컴퓨터비전·음성·내장형 AI
- 정답인 AI 조언과 틀린 AI 조언, 수용해야 하는 사례와 거부해야 하는 사례
- 저위험·가역 사례와 권리·안전·취약집단에 영향을 주는 고위험 사례
- 한국어·영어 외 언어 또는 저자원 언어, 방언·문화적 맥락·번역 출력
- 읽기 수준이 낮은 사용자와 쉬운 언어가 필요한 수신자
- 화면낭독기·키보드·자막·텍스트 대체가 필요한 사용자
- 현장·교대근무자, 외부 계약자와 저대역폭·제한된 도구 접근 환경
- 조작된 인용, 번역·재인용으로 범위가 변한 출처와 접근 불가능한 원출처
- Content Credentials가 유효·손상·없음·미지원인 콘텐츠

자세한 지시나 반복 프롬프트, 유창성, 설명, 인간 검토자 또는 provenance 표시는
정확성·공정성·진실성·적법성을 자동 보증하지 않습니다.

공통 평가 fixture의 최소 25%는 비생성형 AI 사례로 구성하고 모든 핵심 평가에
비생성형 사례를 최소 1건 포함합니다. 이 비율은 파일럿 전 governance floor이며
대표성 자료가 축적되면 상향 또는 분야별 가중 조정할 수 있습니다.

## 3. 채점 계약

각 fixture는 시행 전에 다음을 고정합니다.

1. 평가 대상 행동과 입력·응답 형식
2. 사전에 심은 핵심 결함·위험 신호와 전체 분모
3. 필수 발견 항목과 허용 가능한 대안
4. 결함의 심각도와 가중치
5. `판단 불가`, 사용 중단과 에스컬레이션이 정답인 조건
6. 사용해야 하는 조직 정책·데이터 분류표·위험 허용도·승인 경로
7. 동등한 대체 입력·응답 방식과 접근성 편의

언어·디지털 숙련도·장애에 따른 편의는 과업 판단의 안전·정확성·근거 기준을
낮추지 않습니다. 과업 판단과 전달 접근성을 별도 점수로 기록하고 어느 한쪽의
치명 실패를 평균으로 상쇄하지 않습니다.

치명 조건은 고위험 무승인 채택, 금지 사례 허용, 민감정보 재노출과 근거 없는
진실성·적법성 보증입니다. 이 조건은 평균 점수로 상쇄하지 않습니다.

## 4. 후보별 주요 측정

| 후보 | 주요 측정 |
|---|---|
| AI 기초·한계 | 범위 밖 일반화, 확인되지 않은 주장과 언어·집단별 한계 누락 |
| 과업 프레이밍 | 필수 제약 충족, 교정 근거의 질과 안전한 중단 |
| 출력 적합성 | 심각도별 핵심 결함 탐지와 유해한 잘못된 채택 |
| 위험 비례 의존 | 제공된 정책 안의 최소검증, 승인·중단·이관 선택 |
| 신뢰 보정 | 올바른 수용·거부, 독립 초기판단과 결정 변경 근거 |
| 책임 있는 사용 | 금지 사례 허용, 민감정보 재노출과 안전한 대안 |
| 영향 인식 | 사전에 심은 간접 대상자·취약집단 탐지와 전문 이관 |
| 사용 투명성 | 필수 고지와 수신자의 역할·한계·교정 경로 이해 |
| 근거 검증 | 주장–원출처 연결, 미확인 표시와 범위 밖 인용 |
| provenance | 유효·손상·없음·미지원 구분과 별도 사실 검증 선택 |

## 5. 제한과 파일럿 항목

- 역할·업종별 난이도와 합격선은 아직 확정하지 않았습니다.
- 적절한 의존에는 단일 보편 지표가 없으므로 AI 정확도·오류 기저율·역할
  전문성을 고정한 충분한 표본에서 수용과 거부를 별도로 측정합니다.
- 포용성 fixture의 언어·장애·접근환경 표본은 실제 대상자 검토와 파일럿을 거쳐야
  합니다.
- 조직 정책과 위험 분류가 제공되지 않은 상태에서 학습자에게 법률·통제체계를
  발명하게 하지 않습니다.
