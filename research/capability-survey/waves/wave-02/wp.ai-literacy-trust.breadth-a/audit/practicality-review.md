## 후보별 교정

| 후보 | 반영 |
|---|---|
| AI 기초·한계 | 안내형 D1을 추가하고 언어·방언·집단·접근 방식별 성능 차이를 포함 |
| 과업 프레이밍 | 임의 교정 횟수를 제거하고 구조적 편향을 프롬프트로 해결한다는 오해를 공통 계약에서 차단 |
| 출력 적합성 | 독자의 언어·읽기 수준·문화·접근성 요구와 심은 핵심 결함·유해 채택을 평가 |
| 위험 비례 의존 | 제공된 위험 매트릭스와 최소검증 안에서 평가하고 취약집단·언어·접근성 영향을 추가 |
| 신뢰 보정 | AI 정확도·오류 기저율·전문성을 고정하고 올바른 수용·거부를 별도 측정 |
| 책임 있는 사용 | 제공된 정책·분류표·이관 지도 안에서만 D2를 평가하고 민감정보 재노출을 치명 조건으로 지정 |
| 영향 인식 | 표본별 필수 간접 대상자·취약집단을 사전 고정하고 추가 발견은 근거의 질로 평가 |
| 사용 투명성 | 쉬운 언어·다국어·화면낭독·자막·대체텍스트와 수신자 이해도 검사 추가 |
| provenance | 없음·제거·미지원·오프라인·접근 불가 사례와 별도 사실 검증 선택을 평가 |

기존 Unit 병합 후보인 근거·출처 검증은 최초 감사에서 pass였습니다. 조작 인용,
번역·재인용, 비영어 원출처와 접근 불가능한 출처 fixture는 공통 평가 계약에
후속 항목으로 기록했습니다.

## 생성형 AI 편향 방지

- 상세 지시와 반복 프롬프트가 구조적 편향을 해결한다고 가정하지 않습니다.
- 유창성·자신감·설명을 정확성이나 공정성의 증거로 사용하지 않습니다.
- 평균 성능을 특정 언어·집단·장애 맥락에 일반화하지 않습니다.
- 인간 검토자가 있다는 이유로 자동화 편향·차별 위험이 제거된다고 보지 않습니다.
- provenance와 AI 생성 라벨을 진실성·적법성·저작권 보증으로 사용하지 않습니다.

## 결론

P0는 없었고 P1을 후보와 공통 평가 계약에 반영했습니다. 역할별 깊이와 합격선은
파일럿 전까지 확정하지 않으며, 포용성 fixture는 실제 대상자 검토가 필요한
불확실성으로 남깁니다. 수정 후 같은 읽기 전용 감사자가 재확인한 결과 P0 0건,
P1 0건입니다. 역할·업종별 합격선, 실제 대상자 검토, 신뢰 보정 표본 수,
비생성형 AI 최소 비율과 관할별 고지 연결은 P2 파일럿 항목으로 남습니다.
