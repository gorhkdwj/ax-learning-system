## P1 교정

- 공통 평가계약에 query·변환·저장·backfill·재학습·인간 검토의 시간·금액·
  자원 한도와 한도 초과 시 중단·판단 불가·인간 이관을 명시했습니다.
- backfill·지표 변경·격리 해제·threshold·재학습·rollback의 인간 승인점과
  승인 거부·취소·무응답 시 외부 변경 0건·원본 보존·감사로그를 고정했습니다.
- 원천 계약은 모든 요구를 학습자에게 공개하고 평가자에게 정답 목록과 위반
  위치만 숨기도록 교정했습니다.
- 데이터 품질은 calibration과 봉인 holdout을 분리하고 임계값 사전 고정,
  접근 횟수, 최소 검출률과 최대 오탐률을 기록합니다.
- 예측 ML 검증은 test label을 봉인하고 단 한 번 실행하며 dataset hash·접근
  횟수·설정 이력과 preprocessing 누수, baseline go/no-go를 검사합니다.
