# Claude Code 통합 작업공간 진입점

공개 학습 시스템의 Phase 2 조사 에이전트와 프로젝트 설정은
`ax-learning-system/.claude/`에 있습니다. 해당 작업을 시작할 때에는 공개
저장소를 작업 디렉터리로 사용하십시오.

```powershell
Set-Location ./ax-learning-system
claude
```

Vault 작업은 `ax-learning-vault/`에서 별도 세션으로 수행하십시오. 원문이나
비공개 산출물을 공개 저장소 세션의 컨텍스트에 불필요하게 포함하지 마십시오.
