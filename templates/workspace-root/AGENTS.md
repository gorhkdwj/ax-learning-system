# AX 통합 작업공간 에이전트 지침

## 언어와 대화

- 모든 사용자 응답은 격식 있는 한국어 합쇼체로 작성합니다.
- 확인된 사실, 해석, 가정과 불확실성을 구분합니다.
- 학습 범위나 난이도를 크게 바꾸는 판단은 사용자와 함께 결정합니다.

## 저장소 경계

이 디렉터리는 두 저장소를 함께 여는 상위 작업공간이며 자체 Git 저장소가 아닙니다.

- `ax-learning-system/`: 공개 가능한 학습 시스템, 메타데이터, 코드와 예제
- `ax-learning-vault/`: 원문, 개인 기록, 임베딩과 비공개 생성물
- `.remember/`: 로컬 에이전트 세션 상태이며 어느 저장소에도 포함하지 않음

공개 저장소는 Vault가 없어도 검증과 공개 예제로 정상 작동해야 합니다.
Vault의 파일 전문, 개인 정보, 로컬 절대경로, 임베딩과 비공개 생성물을 공개
저장소에 복사하지 않습니다. 공개 자료에는 필요한 경우 출처 URL, 공개 가능한
요약과 불투명한 원천 ID만 둡니다.

## 작업 라우팅

학습 시스템, 조사, 스키마, HUB와 공개 콘텐츠를 변경할 때에는 먼저
`ax-learning-system/AGENTS.md`를 따릅니다. 그 파일에서 지정한 필수 문서는
공개 저장소 루트를 기준으로 읽습니다.

원문 수집, 개인 학습 기록, 비공개 인덱스와 임베딩을 다룰 때에는
`ax-learning-vault/AGENTS.md`를 따릅니다.

두 영역을 연결하는 기능을 변경할 때에는 추가로
`ax-learning-system/docs/architecture/public-private-storage.md`를 읽습니다.

## 경로와 실행 원칙

- 각 저장소 내부 메타데이터에는 해당 저장소 루트 기준 상대경로를 사용합니다.
- 공개 코드에서 Vault 경로는 `AX_VAULT_ROOT` 또는 공통 경로 해석기를 통해서만
  얻습니다.
- 공개 코드에 사용자의 절대경로를 기록하지 않습니다.
- 하나의 명령으로 두 저장소를 함께 커밋하거나 푸시하지 않습니다.
- 상위 작업공간에서 공개 시스템 전체를 검증할 때에는 다음을 실행합니다.

```powershell
.\ax-learning-system\tools\verify.ps1
```
