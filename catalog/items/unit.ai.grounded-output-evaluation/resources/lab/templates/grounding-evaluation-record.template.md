# 근거 연결 평가 기록

- 평가 대상: `교체: 시스템 또는 실행 식별자`
- 표본 수: `교체: N건`
- 판정 기준 고정일: `교체: YYYY-MM-DD`
- 평가자: `교체: 이름`
- 평가일: `교체: YYYY-MM-DD`

판정 기준은 평가를 시작하기 전에 고정합니다. 평가 도중에 기준을 바꾸면 집계를
비교할 수 없습니다.

## 주장별 판정

| 표본 | # | 주장 | 판정 | 실패 구간 | 비고 |
|---|---:|---|---|---|---|
| `S1` | 1 | `교체: 출력에서 뽑은 주장` | `근거 있음 / 근거 부족 / 모순 / 판단 불가` | `해당 없음 / 검색 누락 / 근거 무시` | `교체: 근거 묶음 확인 결과` |
| `S1` | 2 | | | | |

`실패 구간`은 근거 묶음을 직접 열어 확인한 뒤에만 적습니다. 짐작으로 적지
않습니다.

## 보류 판정

| 표본 | 출력이 보류했나 | 근거에 답이 있었나 | 분류 |
|---|---|---|---|
| `S1` | `예 / 아니오` | `예 / 아니오` | `정상 / 보류 오류 / 올바른 보류 / 허구 생성` |

## 집계

| 항목 | 수 | 비율 |
|---|---:|---:|
| 전체 주장 | `교체: N` | 100% |
| 근거 있음 | | |
| 근거 부족 | | |
| 모순 | | |
| 판단 불가 | | |

| 실패 구간 | 수 |
|---|---:|
| 검색 누락 | |
| 근거 무시 | |

| 보류 분류 | 수 |
|---|---:|
| 올바른 보류 | |
| 보류 오류 | |
| **허구 생성** | |

`올바른 보류`는 오답에서 제외합니다. 근거가 없을 때 답하지 않은 것은 옳은
동작입니다.

## 판단

- 먼저 고칠 구간: `교체: 검색 또는 생성`
- 근거: `교체: 위 집계 중 어느 수치가 그렇게 가리키는지`
- 다음 측정 시점: `교체: 언제 다시 재는가`
- 이 평가로 답할 수 없는 것: `교체: 표본 편향, 도메인 한계 등`
