# 주장–근거 기록

- 검증한 자료: `교체: 자료 제목과 출처`
- 자료 형태: `교체: AI 생성 요약 / 아티클 / 브리핑 / 기타`
- 검증자: `교체: 이름`
- 검증일: `교체: YYYY-MM-DD`

## 주장별 판정

| # | 주장 | 판정 | 출처 | 확인 범위 | 확인일 |
|---:|---|---|---|---|---|
| 1 | `교체: 확인 가능한 주장 한 줄` | `지지됨 / 부분 지지 / 미확인 / 반박됨` | `교체: URL 또는 없음` | `교체: 원문에서 실제로 읽은 부분` | `교체: YYYY-MM-DD` |
| 2 | | | | | |

`확인 범위`에는 "전체 읽음"이 아니라 실제로 읽은 절·표·페이지를 적습니다.
읽지 않은 부분을 근거로 쓰지 않기 위한 열입니다.

## provenance 신호

자료에 이미지·영상이 없으면 이 절을 삭제하지 말고 `해당 없음`이라고 적습니다.

| 대상 | 자격 증명 상태 | 별도 사실 검증 필요 | 근거 |
|---|---|---|---|
| `교체: 이미지·영상 식별` | `유효 / 손상 / 없음 / 미지원` | `필요 / 불필요` | `교체: 판단 근거` |

자격 증명 상태는 내용의 사실성과 무관합니다. `유효`여도 별도 검증이 필요할 수
있습니다.

## 해석과 미확인 가정

주장은 아니지만 자료가 전제하거나 암시하는 것을 적습니다.

- `교체: 자료가 사실처럼 다루지만 확인되지 않은 전제`

## 종합

- 확인 가능한 주장 수: `교체: N`
- `지지됨`: `교체: N` / `부분 지지`: `교체: N` / `미확인`: `교체: N` / `반박됨`: `교체: N`
- 출처가 있으나 주장을 직접 지지하지 않은 사례: `교체: N건과 해당 번호`
- 이 자료를 후속 산출물에 쓸 때의 제약: `교체: 무엇을 인용할 수 있고 무엇을 못 쓰는지`
