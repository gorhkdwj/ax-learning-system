# 주장–근거 기록 실습

이 실습은 `unit.foundation.evidence-verification@1.0.0`의 D1과 D2 학습성과를
다룹니다. 목표는 빠르게 판정하는 것이 아니라 **다른 사람이 같은 자료로 같은
결론에 도달할 수 있는 기록**을 남기는 것입니다.

## 준비물

- 검증할 자료 1건. AI가 생성한 요약·브리핑이면 좋습니다.
- 웹 브라우저와 표 편집기 또는 Markdown 편집기

특정 도구를 쓰지 않습니다. 도구 조작이 아니라 판정과 기록이 학습 대상입니다.

## 절차

### 1단계. 주장 분해

자료에서 **확인 가능한 주장**만 골라 한 줄씩 분리합니다.

- 수치, 날짜, 인용, 인과 서술, 제품·기능의 존재 여부가 대상입니다.
- 의견, 권고, 전망은 주장이 아니므로 제외합니다.
- 한 문장에 주장이 둘 이상이면 나눕니다.

### 2단계. 출처 연결

각 주장에 출처를 답니다. 출처는 다음 순서로 찾습니다.

1. 표준·공식 사양
2. 공식 문서·공식 소스코드
3. 1차 연구
4. 그 외 2차 자료

**출처가 있다는 것과 그 출처가 주장을 지지한다는 것은 다릅니다.** 출처를 열어
해당 주장이 실제로 그 안에 있는지 확인합니다. 원문에 없으면 `미확인`으로
표시합니다. 이 구분이 이 실습의 핵심입니다.

### 3단계. 상태 판정

각 주장을 다음 중 하나로 판정합니다.

| 판정 | 뜻 |
|---|---|
| `지지됨` | 출처 원문이 주장을 직접 지지합니다 |
| `부분 지지` | 출처가 일부만 지지하며 범위가 다릅니다 |
| `미확인` | 출처를 찾지 못했거나 원문이 주장을 다루지 않습니다 |
| `반박됨` | 출처가 주장과 다른 내용을 말합니다 |

### 4단계. provenance 신호 처리

자료에 이미지·영상이 있고 Content Credentials 같은 provenance 정보가 있으면
상태를 함께 기록합니다.

| 상태 | 뜻 |
|---|---|
| `유효` | 자격 증명이 검증됩니다 |
| `손상` | 자격 증명이 있으나 검증에 실패합니다 |
| `없음` | 자격 증명이 없습니다 |
| `미지원` | 형식이나 환경이 확인을 지원하지 않습니다 |

**네 상태 모두 내용의 사실성과 무관합니다.** `유효`가 내용이 참이라는 뜻이
아니고 `없음`이 거짓이라는 뜻도 아닙니다. 자격 증명 상태와 사실 검증 필요를
반드시 분리해 적습니다. 자세한 근거는 같은 Unit의
`resource.foundation.evidence-verification.content-provenance-reference@1.0.0`를
참조하십시오.

### 5단계. 기록 작성

`templates/claim-evidence-record.template.md`를 복제해 채웁니다. 각 행에 확인일과
확인 범위를 반드시 적습니다. 확인 범위란 원문에서 실제로 읽은 부분을 말합니다.

## D1 완료 기준

안내된 절차를 따라 자료 1건의 기록을 완성했고 다음을 모두 만족합니다.

- 모든 확인 가능한 주장이 분리되어 있습니다.
- 각 주장에 판정과 확인일이 있습니다.
- provenance가 있는 자료라면 네 상태 중 하나로 판정하고 사실 검증 필요를
  별도 열에 적었습니다.

## D2 완료 기준 — 전이과제

**새로운 자료 1건**을 안내 없이 처음부터 검증합니다. 1단계에서 쓴 자료와 주제가
다른 것을 고릅니다. 다음을 모두 만족해야 합니다.

- 각 핵심 주장에 출처 또는 `미확인` 표시가 있고 확인 범위와 확인일이 있습니다.
- 사실, 해석, 미확인 가정을 구분했습니다.
- **출처가 달려 있으나 주장을 직접 지지하지 않는 사례를 최소 1건 찾아냈습니다.**
  못 찾았다면 2단계에서 원문을 열지 않았을 가능성이 높으므로 다시 확인합니다.
- provenance가 유효한데도 내용에 별도 검증이 필요한 사례를 설명할 수 있습니다.

## 자주 나오는 실패

- **출처 링크만 보고 지지됨으로 판정** — 가장 흔합니다. 원문을 열어야 합니다.
- **범위가 다른 출처를 지지됨으로 처리** — 다른 연도, 다른 제품 버전, 다른
  국가의 자료가 흔히 이렇게 섞입니다. `부분 지지`가 맞습니다.
- **미확인을 반박됨으로 적음** — 찾지 못한 것과 반박된 것은 다릅니다.
- **자격 증명 유효를 내용 진실성으로 확대 해석** — 4단계의 경계입니다.

## 검증

이 실습은 자동 채점기가 없습니다. 기록의 각 행이 위 완료 기준을 만족하는지
사람이 확인합니다. 자동 검사 통과와 업무적으로 올바른 판정은 다릅니다.
